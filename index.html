How to use

Topics panelPick a course topic, read the explanation, type values, then press a build button
Double-click empty spaceAdd a node there
Double-click node / cellEdit its value (Enter to save, Esc to cancel, Shift+Enter for a new line in boxes and notes)
Drag the ● handleCreate a link. Drop on empty space to create a new linked node
C Link modeDrag node → node, or click source then target. From an array cell, links start at that cell
Double-click a linkCycle next → prev → edge
Drag an arrow's endRe-point it to another node, e.g. node.prev = x. Grab near the arrowhead, or click the arrow and drag one of its round handles. The start end works too
Arrow Label…Name an arrow (e.g. left, right). Pointers then offer curr = curr.left
Drag empty spacePan · Shift+drag to box-select · wheel to zoom
Moving a SetAlso moves the nodes inside it. Resize from the bottom-right corner
V CMove tool / Link tool
N A P K S U TAdd node, array, pointer, key/value box, set, null, note (at the cursor)
1–7Color: default, green, yellow, red, blue, purple, gray
Click a pointerMenu with every move from where it points (.next, .prev, .left, .right, graph neighbours, i++), point to…, = null, rename
Drag a pointer onto a nodeIt snaps there and now points to that node / array cell
Pointer selected + → / ←Move it to next / prev (arrays: i++ / i--). Shift+arrows nudges instead
RReverse selected links (great for list reversal)
] / [Array: insert cell after selected / remove selected cell
Enter / F2Edit selected
Del · Ctrl+D · Ctrl+ADelete · duplicate · select all
Ctrl+Z / Ctrl+YUndo / redo
ArrowsNudge selection (Shift = bigger steps)
F · 0 · G · BFit view · reset zoom · snap to grid · toggle topics panel
